# Likeness AI

**Your face. Your terms. Verified by your channel.**

Creators connect their YouTube channel (proving it's theirs), pass a live face check matched to their
channel avatar, and license their likeness for AI image and video ads, priced by their audience. Brands
generate consented ads in minutes and pay per render; creators approve every licence and can revoke at
any time. Anyone can check whether a file was licensed: Licensed, Expired, Revoked or Unknown.

Built on Google Cloud for the AI Builder Cup 2026: Vertex AI (Gemini image generation and a Gemini
safety filter; Veo 3.1 Lite for video), Firebase Auth with the YouTube Data API, Firestore, Cloud KMS
envelope encryption and receipt signing, Cloud Storage, Secret Manager and Cloud Run.

Setup and deployment: [docs/deploy-gcp.md](docs/deploy-gcp.md). The full write-up is coming in Phase 3.
